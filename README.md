## 📖 About

This repository contains all the **Data Structures Lab** programs implemented in **C** during the **3rd Semester** of the **B.Tech CSE** curriculum.

It covers fundamental data structures, algorithms, searching, sorting, trees, graphs, hashing, and problem-solving programs commonly asked in university lab exams and coding interviews.
